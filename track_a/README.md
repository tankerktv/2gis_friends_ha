# Трек А закрыт

`GET https://zond.api.2gis.ru/api/1.1/sharing/sessions` в HAR веб-версии
**не вызывается ни разу** — этого запроса в потоке friendsList нет.
Координаты друзей приходят только по WebSocket, поэтому REST-поллинга не будет.
Рабочий вариант — `bridge/` (трек Б).

`probe_sessions.py` оставлен: если захочется перепроверить эндпоинт руками
(мало ли, он существует, просто веб им не пользуется):

```bash
python track_a/probe_sessions.py --token "<40hex access_token>"
```

Скрипт перебирает `Bearer` / `X-Token` / `?token=` / `?access_token=` /
только-cookie и говорит, есть ли в ответе гео-признаки. Судя по всему, вернёт
403/404 на всех вариантах.
